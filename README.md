# Зерно и помол — учебный интернет-магазин

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Дисциплина: «Фронтенд и бэкенд разработка».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина
свежеобжаренного кофе, кофемолок и аксессуаров для заваривания кофе дома.
Сайт сделан без CSS-фреймворков. JavaScript используется только для открытия
и закрытия модального окна и для проверки форм.

## Используемые технологии

- HTML5: семантическая разметка, формы, таблицы, `<dialog>`, `<details>`;
- CSS3: переменные, Flexbox, Grid, позиционирование, `:has()`, `:target`;
- минимальный JavaScript без библиотек;
- Git, GitHub, GitHub Pages.

## Обязательные страницы

| Страница | Содержимое |
| --- | --- |
| `index.html` | hero-блок, преимущества, категории, популярные товары, отзывы, промо-блок |
| `catalog.html` | 9 карточек товаров в 4 категориях, фильтр по категориям |
| `product.html` | изображение, описание, цена, наличие, таблица характеристик, сравнение комплектаций, отзывы, похожие товары, кнопки заявки и быстрого заказа |
| `order.html` | форма заявки, шаги оформления, таблица условий доставки |
| `contacts.html` | адрес, телефон, часы работы, форма обратной связи, маршрут, вопросы и ответы |

У каждой страницы свои `title` и `meta description`. На всех страницах
одинаковые шапка, меню и подвал, подключён общий `css/style.css`,
есть один `main`.

## Как выполнены требования

- **Семантика:** `header`, `nav`, `main`, `section`, `article` (карточки
  товаров и сам товар), `aside` (фильтр, промо-блок, шаги заказа), `footer`,
  `address`, `figure`/`blockquote` (отзывы).
- **Навигация:** единое меню. Активный пункт отмечен классом
  `site-nav__link--active` и атрибутом `aria-current="page"`. На страницах,
  кроме главной, есть хлебные крошки.
- **Якорные ссылки:** `index.html#advantages`, `#popular`, `#contacts`,
  `catalog.html#grinders`, `contacts.html#faq`. На странице товара есть меню
  разделов `#description`, `#specs`, `#compare`, `#reviews`.
- **Карточки:** название, категория, описание, цена, кнопки «Подробнее»
  и «В заявку», бейджи «Хит», «Новинка» и скидка.
- **Таблицы:** характеристики и сравнение комплектаций на `product.html`,
  условия доставки на `order.html`. В каждой есть `caption`, `thead`,
  `tbody`, `th` с `scope` и `td`.
- **Формы:** заявка (`order.html`), обратная связь (`contacts.html`),
  быстрый заказ в модальном окне (`product.html`). У каждого поля есть
  `label` с совпадающими `for`/`id` и атрибут `name`. Используются
  `required`, `type="email"`, `pattern` для телефона и `minlength`.
- **Модальное окно:** `<dialog>` с методами `showModal()` и `close()`.
- **CSS-переменные:** блок `:root` с цветами, шрифтами, отступами,
  скруглениями, тенями, размерами и слоями `z-index`.
- **Состояния:** `:hover`, `:active`, `:focus-visible`, `:disabled`,
  `[aria-invalid="true"]` для ошибочных полей, `[open]` у раскрытого вопроса.
- **Flexbox:** шапка, меню, группы кнопок, промо-блок, карточка изнутри
  (кнопки прижаты к низу).
- **Grid:** сетка карточек (`repeat(auto-fill, minmax(240px, 1fr))`),
  раскладка каталога «фильтр + товары», hero-блок, страница товара, заявка,
  контакты, подвал.
- **БЭМ:** блоки `site-header`, `site-nav`, `product-card`, `catalog-filter`,
  `form`, `dialog`, `table`, `badge`, `button`. Элементы: `product-card__title`,
  `form__input` и т. п. Модификаторы: `product-card--sale`,
  `product-card--sold-out`, `button--secondary`, `badge--new`,
  `site-nav__link--active`.
- **Позиционирование:**
  - `sticky`: шапка, фильтр каталога и шаги заказа;
  - `relative` + `absolute`: бейдж на карточке и номера шагов заказа;
  - `fixed`: кнопка «Наверх»;
  - `z-index`: значения заданы переменными `--z-*`.

## Самостоятельные доработки

1. **Своя визуальная концепция:** магазин кофе «Зерно и помол», кофейная
   палитра в переменных, акцентный шрифт заголовков, собственные
   SVG-иллюстрации в `images/`.
2. **Фильтр каталога на чистом CSS.** Ссылки фильтра ведут на якоря
   (`#beans`, `#grinders` и т. д.). Активный якорь становится `:target`,
   а `:has()` скрывает карточки других категорий и подсвечивает выбранный
   пункт. Фильтр работает и по ссылке с другой страницы: плитки категорий
   на главной ведут на `catalog.html#beans` и т. п.
3. **Варианты карточек через модификаторы:** скидка (старая цена зачёркнута),
   «Нет в наличии» (серое изображение и неактивная кнопка).
4. **Расширенная страница товара:** хлебные крошки, меню разделов,
   две таблицы, отзывы, блок «С этим товаром покупают».
5. **Дополнительные блоки:** категории, отзывы и промо на главной; шаги
   оформления и таблица доставки на странице заявки; маршрут и FAQ на
   `<details>` на странице контактов.
6. **Три формы вместо одной.** Один скрипт обслуживает все формы через
   атрибут `data-validate`. Подсветка ошибки снимается, как только поле
   исправлено. После отправки появляется сообщение с `role="status"`,
   и на него переходит фокус.
7. **Улучшенное модальное окно:** закрывается кнопкой «×», кнопкой «Отмена»,
   клавишей Esc и кликом по фону. Товар передаётся в скрытое поле формы.
8. **Доступность:**
   - ссылка «Перейти к основному содержимому»;
   - видимый фокус, который меняет цвет на тёмном фоне;
   - `fieldset`/`legend` в форме заявки;
   - `aria-describedby` для подсказок к полям;
   - текст оценки в отзывах для программ экранного доступа;
   - контрастные рамки полей;
   - учёт настройки `prefers-reduced-motion`.
9. **Удобство:**
   - плавная прокрутка к якорям с отступом под липкую шапку
     (`scroll-padding-top`);
   - выбранный способ доставки подсвечивается через `:has(:checked)`;
   - на узких экранах сетки перестраиваются в одну колонку.
